# Official AAS JSON schema

`aas.json` is the JSON schema of the AAS metamodel, IDTA-01001-3-2 (`$id`
`https://admin-shell.io/aas/3/2`), from <https://github.com/admin-shell-io/aas-specs>
(`schemas/json/aas.json`, branch `master`, release v3.2.0), licensed under the **Creative Commons
Attribution 4.0 International License (CC BY 4.0)**. © Industrial Digital Twin Association (IDTA).
Unchanged.

`scripts/tests/test_aas_schema.py` validates the output of `trees_to_aas` and `aas_export`
against it.
